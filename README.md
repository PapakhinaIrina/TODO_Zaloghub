# TODO

Простой список задач на React + TypeScript, созданный с Vite. Без сервера и API.

![Скриншот приложения](public/todo-screenshot.png)

## Стек

- React 19 — компоненты и интерфейс приложения.
- TypeScript 5.8 — типизация компонентов и данных.
- Vite 6 — dev-сервер и production-сборка.
- CSS — стилизация и адаптивная вёрстка.
- `localStorage` браузера — хранение задач без backend и API.

## Запуск

Нужны Node.js 22.9.0 и npm. В корне проекта выполните:

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

`npm run build` проверяет TypeScript и собирает приложение в `dist`. Команда
`npm run preview` запускает локальный просмотр production-сборки.

## Возможности

- Добавление задачи кнопкой или Enter, с удалением пробелов по краям.
- Пустые задачи и строки из пробелов запрещены.
- Переключение выполнения чекбоксом или нажатием на текст.
- Удаление задачи.
- Фильтры: все, активные, выполненные; счётчики задач.
- Автоматическое сохранение в localStorage (`zaloghub.tasks.v1`).
- Восстановление после перезагрузки; проверка формата сохранённых данных и сообщения об ошибках хранилища.
- Адаптивный интерфейс, доступные подписи элементов и управление с клавиатуры.

Данные хранятся только в текущем браузере и привязаны к адресу приложения. При очистке данных сайта задачи удаляются.

## Структура

- `src/App.tsx` — оболочка страницы.
- `src/components/TasksList.tsx` — состояние задач, форма, фильтры и сохранение.
- `src/components/ListWrapper.tsx` — список, пустое состояние и счётчики.
- `src/components/TaskItem.tsx` — отдельная задача и её действия.
- `src/components/ErrorMessage.tsx` — сообщение об ошибке.
- `src/helpers/tasks.ts` — чтение, проверка и сохранение задач.
- `src/lib/types.ts` — типы приложения.
- `src/App.css` — стили компонентов и адаптивная вёрстка.
- `src/index.css` — базовые стили.
